COMBAT REFERENCE IDENTITY 1.1.1
For each referenced combatant, explicitly link the intended role to its actual <Picture N> at first introduction, then use the same unambiguous designation throughout the encounter. Picture numbers follow the supplied reference mapping, not fighter order; one image may contain several subjects. Preserve the reference subject's facial features, hair and build instead of replacing identity with a generic physical description. Distinguish identity from costume, abilities and equipment: changes to the latter follow the user's intention and permissions, not an invented new face.
Inline <Picture N> mentions are allowed in the Brief, continuity invariants, opening compositions and action prose. Only the application-owned reference headers must not be copied into those fields. Use only supplied references and respect their roles: an environment/style reference does not define a fighter, and first/last frames retain their assigned instants. With no references, introduce subjects from the intention without inventing Picture labels.
Use role names with the intended meaning: for a combatant wielding fire, use "fire-wielding combatant", not "fire fighter", which suggests a firefighter's occupation and uniform. Apply this principle to the actual requested abilities; do not import this example's fire, costumes or powers into unrelated encounters. Carry the same subject-to-reference associations through every shot and later revision.

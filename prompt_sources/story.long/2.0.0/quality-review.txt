FIDÉLITÉ : compare chaque required_on_screen de unit_requirements aux gestes/paroles réellement présents dans reader_units. Les exigences ne prouvent pas qu’un fait a été joué ; cite ce qui manque au scénario si un moment imposé a disparu. Ne cherche aucune vérité future ni confirmation que l’auteur réserve ; seuls les événements publics de ces unités sont fournis. Préserve l’ironie dramatique et le registre demandé, même cru. Une préférence de style ne doit pas lancer une réécriture. Pour les mots imposés, protected_lines est la source d’auteur ; une citation reformulée dans required_on_screen ne crée pas une nouvelle réplique obligatoire. Compare l’action, le locuteur et le sens de cette preuve ; ne remplace pas une phrase conforme à protected_lines par cette reformulation.
Catégorise chaque issue : clarity (compréhension), fidelity (moment imposé manquant), continuity (contradiction/raccord), speech_estimate (seul calcul de débit/durée), style (préférence), other (autre défaut avéré). Utilise speech_budget pour le débit, pas une cadence implicite plus lente. Une estimation de parole seule est toujours warning ; un véritable maillon dramatique manquant peut être blocking. Ne demande pas de raccourcir une réplique exacte pour satisfaire le seul calcul.

Cause vérifiée : les neuf réponses sont un objet JSON valide entouré d'un bloc Markdown json fermé. Retirer uniquement cet encadrement permet de décoder exactement deux champs texte non vides, `message` et `prompt`. Les six réponses acceptées étaient déjà du JSON brut. Aucun contenu de scène n'est reproduit ici.

La création assistée dispose déjà d'une tolérance aux blocs Markdown dans son propre décodeur : incohérence entre écrans, pas panne de ComfyUI ni manque de tokens.
